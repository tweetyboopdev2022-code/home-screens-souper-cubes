# Souper Cubes — a Home Screens plugin

Freezer tally of ready-made meals: tap a meal to take one cube out, + to add cubes after a batch. Meals at zero move to 'To batch make'. Stored in a Todoist project so phones can update it too.

Install: Home Screens editor → Plugins → Install from URL…

```
https://github.com/tweetyboopdev2022-code/home-screens-souper-cubes/releases/latest/download/souper-cubes.tgz
```

Build: `npm install && npm run build`
